# Mauswag RecordSync: Crop Management Module

## Project Overview
Mauswag RecordSync is a specialized module for the AgriSync ecosystem designed to digitize farm operations. It bridges the gap between field assistants and managers by providing a real-time platform for crop lifecycle tracking.

## Key Features
- **Automated Roadmap Generation:** Instant 90-day task scheduling based on crop variety.
- **Inventory Sync:** Real-time supply deduction logic (`fsStock - fsQtyUsed`).
- **Managerial Oversight:** Approval-based workflow for crop plan activation.
- **Environment Logging:** Integrated weather and field observation reporting.

## Tech Stack
- **Backend:** Java Spring Boot
- **Frontend:** Vanilla JavaScript, HTML5, CSS3
- **Database:** H2 Persistent Relational Database
- **Architecture:** RESTful API with IEEE 830-1998 compliance.
